# 🎸 Guitar Practice Trainer

**A free, interactive practice tool for guitarists looking to improve fretboard fluency, music theory knowledge, and musical recall.**

Guitar Practice Trainer is a browser-based randomizer designed to make practicing scales, modes, triads, chords, and arpeggios more engaging and challenging.

Rather than practicing the same exercises in the same order, users can generate randomized musical challenges tailored to their individual learning goals.

Whether you're learning the major scale, memorizing triad inversions, or developing fluency with extended chords, Guitar Practice Trainer helps turn theoretical knowledge into practical playing skills.

## Features

### 🎰 Six Customizable Randomizers

Enable or disable any combination of six independent slot-machine-style reels:

| Randomizer | Function |
|---|---|
| Root Note | Generates random root notes |
| Scale Degree | Generates scale degrees 1–7 |
| Mode | Generates one of the seven diatonic modes |
| Triad Quality | Major, Minor, Aug, or Dim |
| Triad Inversion | Root Position, 1st, or 2nd Inversion |
| Four-Part Chord Shape | Generates common seventh, sixth, suspended, altered, and extended chord types |

Each reel operates independently, allowing users to customize exercises for their particular practice goals.

Disabled reels remain visible but inactive.

### 🎯 Custom Key Selection

Select which keys you want to practice.

- Choose from all 12 chromatic pitch classes.
- Practice only the keys relevant to your current lessons or assignments.
- Use the existing note options to control natural, sharp, and flat spellings.

### 🎵 Built-In Metronome

Practice with an integrated metronome featuring:

- Adjustable tempo from 40–200 BPM
- 2/4, 3/4, and 4/4 time signatures
- Classic click and woodblock sounds
- Visual beat indicators
- Adjustable tempo increments
- Independent operation while generating new exercises

### 📖 Practice Guide & Examples

An expandable practice guide includes example exercises for scales, modes, triads, inversions, and four-part chord arpeggios.

## How to Use

1. Open the Guitar Practice Trainer in your browser.
2. Select the keys you want to practice.
3. Choose your parent scale and root note options.
4. Enable the randomizer reels relevant to your exercise.
5. Click **Roll Again** to generate a challenge.
6. Play the indicated exercise on your guitar.
7. Repeat, gradually increasing your speed and accuracy.

## Example Practice Exercises

### Exercise 1: Major Scales

**Enable:** Root Note

Generate a random root note, then play its major scale across the fretboard.

Example: Root Note = G

**Challenge:** Play the G major scale ascending and descending.

### Exercise 2: Scale Degrees and Modes

**Enable:** Root Note + Scale Degree

Generate a root note and scale degree, identify the corresponding note and mode, and play the appropriate mode shape.

Example:
- Root Note: C
- Scale Degree: 5

**Challenge:** Play G Mixolydian, the fifth mode of C major.

### Exercise 3: Modes

**Enable:** Root Note + Mode

Generate a random root note and mode.

Example:
- Root Note: C
- Mode: Phrygian

**Challenge:** Play C Phrygian across the fretboard.

### Exercise 4: Triads and Inversions

**Enable:** Root Note + Triad Quality + Triad Inversion

Generate a random triad and inversion.

Example:
- Root Note: F
- Quality: Aug
- Inversion: 2nd

**Challenge:** Locate and play an F augmented triad in second inversion across the fretboard.

### Exercise 5: Four-Part Chord Arpeggios

**Enable:** Root Note + Four-Part Chord Shape

Generate a random chord and play its arpeggio.

Example:
- Root Note: C
- Chord: Min7♭5

**Challenge:** Play C–E♭–G♭–B♭–C ascending and descending.

## Who Is This For?

Guitar Practice Trainer is intended for:

- Beginning and intermediate guitarists developing fretboard knowledge
- Music students working through structured performance requirements
- Guitarists practicing scales, modes, triads, and arpeggios
- Players looking to improve note recognition and theoretical recall
- Guitar teachers seeking a flexible exercise generator for their students

## Technology

Guitar Practice Trainer is built using HTML, CSS, and vanilla JavaScript.

It requires no external libraries, user accounts, or installation. Audio is generated using the browser's Web Audio API.

The trainer can be used directly in a modern web browser.

## Project Background

Guitar Practice Trainer began as a simple scale-degree randomizer developed to support structured guitar study.

The project gradually expanded into a modular practice tool capable of generating a variety of musical exercises while retaining a simple, approachable interface.

Its central goal is to help guitarists move beyond memorized patterns and develop faster, more confident musical recall.
